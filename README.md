# بروشور اجرای دیجیتال — تور کنسرت سرزمین پدری (استاد وحید تاج)

سورس کامل **بروشور اجرای دیجیتال کنسرت** طراحی‌شده با معماری **PHP + فایل JSON (بدون نیاز به دیتابیس MySQL/SQL Server)** و بهینه‌سازی اختصاصی برای **Windows Server + IIS** با پشتیبانی خودکار از ریشه دامنه و زیرپوشه‌ها (`https://negahm.ir/vahidtaj` و `https://negahm.ir/vahid-taj`).

---

## ویژگی‌های کلیدی

- **وفاداری دقیق بصری و رنگی به طرح مرجع فیگما**: پالت کالیبره‌شده سرمه‌ای نفتی (`#16324B` تا `#2A4C6A`)، کارت‌های `#23435F` و کادر طلایی مات آنتیک سوژه (`#CEB21D` تا `#BAA12C`).
- **فهرست قطعات اجرایی تعاملی (۳ حالت هوشمند)**:
  1. قطعات بدون صوت و شعر: نمایش دایره شماره، نام قطعه و متادیتا (`آهنگساز` • `شعر` • `تنظیم` • `به نوازندگی / بی‌کلام`).
  2. قطعات دارای فایل صوتی: نمایش دکمه پخش دایره‌ای، نوار زمان تعاملی (`۰۰:۰۰`) با دستگیره حلقه‌دار و دکمه دانلود مستقیم.
  3. قطعات دارای شعر: نمایش دکمه بازشوی دایره‌ای و کشوی نقطه‌چین **«متن قطعه»** با تفکیک نوری مصرع‌های زوج و فرد.
- **پنل مدیریت کاملاً مستقل (`/admin`)**: بدون هیچ لینکی در صفحه عمومی بروشور، قابل دسترس صرفاً از طریق آدرس مستقیم دامنه، مجهز به آپلود مستقیم صوت قطعات، آپلود فونت اختصاصی (`.woff2/.woff/.ttf/.otf`)، ویرایش تمامی بخش‌ها، مدیریت سئو و پشتیبان‌گیری JSON.
- **سئوی حرفه‌ای ویژه زیرپوشه (`negahm.ir/vahidtaj` و `negahm.ir/vahid-taj`)**: تشخیص خودکار آدرس Canonical، متاتگ‌های کامل OpenGraph و Twitter، اسکیما `MusicEvent` + `BreadcrumbList` گوگل، فاوآیکون اختصاصی تصویر استاد وحید تاج در قاب مستطیل طلایی، و تولید خودکار `sitemap.xml` و `robots.txt`.

## ساختار پوشه‌ها در IIS

```text
vahid/
├── index.php                # صفحه اصلی بروشور اجرای دیجیتال
├── sitemap.php              # نقشه سایت پویا (XML)
├── sitemap.xml              # نقشه سایت ایستا (بروزرسانی خودکار از پنل)
├── robots.txt               # تنظیمات ربات‌های جستجوگر
├── favicon.ico              # فاوآیکون چندسایزی مرورگر
├── web.config               # پیکربندی کامل IIS (MIME فونت و صوت، سقف آپلود ۲۰۰MB، امنیت)
├── admin/                   # پنل مدیریت مستقل (جدا از سایت اصلی)
│   ├── index.php            # داشبورد مدیریت تمام بخش‌ها، صوت، فونت و سئو
│   ├── login.php            # صفحه ورود مدیر
│   └── logout.php           # خروج امن از نشست
├── includes/                # هسته PHP، احراز هویت، ذخیره‌سازی JSON و موتور رندر سئو
├── assets/                  # استایل‌ها، اسکریپت پلیر، تصاویر برش‌خورده و فونت پیش‌فرض
├── data/                    # دیتابیس JSON محافظت‌شده با data/web.config و .htaccess
│   ├── site.json            # داده‌های کامل بروشور
│   └── admin.json           # نام کاربری و هش bcrypt رمز عبور مدیر
└── uploads/                 # محل ذخیره فایل‌های آپلودی از پنل (audio / fonts / images)
```

## راهنمای نصب سریع روی Windows Server + IIS

1. اطمینان حاصل کنید **PHP 7.4 یا PHP 8.x** از طریق **FastCGI** روی IIS فعال است (مثلاً توسط *PHP Manager for IIS*).
2. محتویات پروژه را در مسیر زیرپوشه مورد نظر خود روی هاست یا سرور ویندوز کپی کنید؛ برای مثال:
   - `C:\inetpub\wwwroot\negahm\vahidtaj` -> آدرس سایت: `https://negahm.ir/vahidtaj`
   - یا `C:\inetpub\wwwroot\negahm\vahid-taj` -> آدرس سایت: `https://negahm.ir/vahid-taj`
   *(سیستم به‌صورت خودکار مسیر زیرپوشه را تشخیص می‌دهد و نیازی به ویرایش کد نیست).*
3. روی دو پوشه **`data`** و **`uploads`** راست‌کلیک کرده و در تب `Security` به یوزرهای **`IIS_IUSRS`** و **`IUSR`** دسترسی **Modify / Write** بدهید تا ذخیره تغییرات پنل و آپلود صوت/فونت بدون خطا انجام شود.
4. برای افزایش حجم مجاز آپلود فایل‌های صوتی در `php.ini` مقادیر زیر را بررسی کنید:
   ```ini
   file_uploads = On
   upload_max_filesize = 100M
   post_max_size = 120M
   ```
5. آدرس پنل مدیریت مستقل:
   - `https://negahm.ir/vahidtaj/admin/` یا `https://negahm.ir/vahid-taj/admin/`
